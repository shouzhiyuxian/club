# 高校社团成员管理系统

✨ **基于 Django 和 MySQL 的高校社团成员管理系统** ✨：一个完整的社团管理平台，支持社团管理、成员管理、活动管理、活动报名等功能。前端后端不分离，Web 应用增删改查数据库。详细注释，高度封装，易复用。

## 系统功能

### 数据仪表盘（首页）

- 统计卡片：社团总数、成员总数、活动总数、报名总数，可点击跳转对应列表。
- **各社团成员数**：柱状图展示各社团成员数量（前 10 个）。
- **活动状态分布**：饼图展示报名中/进行中/已结束/已取消占比。
- **近6个月活动趋势**：折线图按创建月份统计活动数量。
- **成员年级分布**：横向柱状图展示大一至研究生人数分布。

### 核心功能模块

1. **社团管理**
   - 社团信息的增删改查
   - 社团基本信息：名称、简介、成立日期、社长、联系方式等
   - 社团状态管理（正常、暂停、解散）

2. **部门管理**
   - 社团内部门的管理
   - 部门与社团的关联
   - 部门信息的增删改查

3. **角色管理**
   - 成员在社团中的角色定义（仅两种：**社长**、**普通成员**，对应系统三种身份：管理员、社长、成员）
   - 角色信息的增删改查

4. **成员管理**
   - 成员信息的增删改查
   - 成员基本信息：学号、姓名、性别、年级、专业、联系方式等
   - 成员与社团、部门、角色的关联
   - 成员状态管理（正常、请假、退社）
   - 支持按社团筛选成员

5. **活动管理**
   - 社团活动的增删改查
   - 活动信息：名称、描述、地点、时间、参与人数限制等
   - 活动状态管理（报名中、进行中、已结束、已取消）
   - 活动详情查看，包含报名列表

6. **活动报名管理**
   - 成员活动报名的增删改查
   - 报名状态管理（已报名、已参加、已取消、未参加）
   - 自动更新活动的当前参与人数
   - 防止重复报名

7. **管理员管理**
   - 管理员账户的增删改查
   - 密码重置功能
   - 登录认证

8. **招新管理**
   - 招新批次：按社团创建招新批次（名称、开始/结束日期、状态：报名中/已结束）
   - 招新报名：学号、姓名、性别、年级、专业、联系方式、申请部门、状态（待审核/已通过/已拒绝）
   - 审核通过：将报名记录转为正式成员（自动加入对应社团与部门，角色为普通成员）
   - 支持按批次、状态筛选报名列表

9. **导出**
   - 社团列表、成员列表、活动列表、活动报名列表、招新批次列表、招新报名列表均支持导出为 Excel（.xlsx）
   - 导出时沿用当前列表的搜索/筛选条件

## 安装与使用

### 1. 安装依赖

```bash
pip install -r requirement.txt
```

### 2. 配置数据库

打开 `Learntest/settings.py`，找到数据库配置部分（约第92行）。

如果使用 MySQL（推荐），配置如下：

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'club',  # 数据库名称
        'USER': 'root',  # 数据库用户名
        'PASSWORD': 'root',  # 数据库密码
        'HOST': '127.0.0.1',  # 数据库主机
        'PORT': '3306',  # 数据库端口
    }
}
```

**注意**：请先手动创建名为 `club` 的数据库。

如果使用 SQLite，取消注释 SQLite 配置并注释掉 MySQL 配置即可。

### 3. 初始化数据库

```bash
# 生成迁移文件
python manage.py makemigrations

# 执行迁移
python manage.py migrate
```

### 4. 创建管理员账户

进入 Django shell：

```bash
python manage.py shell
```

执行以下命令创建管理员：

```python
from app01.utils.md5 import get_md5
from app01.models import MyAdmin

# 创建管理员账户
# 用户名：admin，密码：12345678
MyAdmin.objects.create(
    id="admin",
    user_name="admin",
    password=get_md5("12345678")
)
exit()
```

### 5. 运行系统

```bash
python manage.py runserver
```

如果默认 8000 端口被占用，可以指定其他端口：

```bash
python manage.py runserver 8008
```

### 6. 访问系统

- **首页（仪表盘）**：http://127.0.0.1:8000/
- **登录页面**：http://127.0.0.1:8000/login/

### 7. 填充假数据（可选）

若需快速查看仪表盘图表效果，可执行：

```bash
python manage.py seed_data
```

将自动创建若干社团、部门、角色、成员、活动及报名记录。若需先清空再填充，可使用：

```bash
python manage.py seed_data --clear
```

**默认登录信息**：
- 管理员：用户名 `admin`，密码 `12345678`
- 成员：账号填**学号**，密码默认 `123456`（后台添加或招新通过时自动设置）

### 三种视角与登录

- **管理员**：使用「管理员账户」中的用户名 + 密码登录。可访问全部功能（社团/部门/角色/成员/活动/报名/招新/管理员账户）。
- **社长**：使用**学号** + 密码登录（角色为社长的成员）。仅能查看和管理**本社团**的部门、成员、活动、活动报名、招新；不能访问「管理员账户」、不能添加/删除社团。
- **普通成员**：使用**学号** + 密码登录。仅能访问：仪表盘、我的信息、我的报名、可报名活动（自助报名本社团的「报名中」活动）。

登录页统一为「账号 + 密码」：管理员填用户名，成员填学号；密码规则一致（MD5 加密存储）。新添加或招新通过的成员默认密码为 `123456`，可在「我的信息」中修改密码。

## 数据模型说明

### 主要数据模型

1. **Club（社团）**
   - 社团基本信息：名称、简介、成立日期、社长、联系方式、状态

2. **Department（部门）**
   - 部门信息：名称、所属社团、简介

3. **Role（角色）**
   - 角色信息：名称、级别(1=社长、2=普通成员)、描述

4. **Member（成员）**
   - 成员信息：学号、姓名、性别、年级、专业、联系方式、所属社团、所属部门、角色、加入时间、状态、登录密码（可选，用于社长/成员登录）

5. **Activity（活动）**
   - 活动信息：名称、所属社团、描述、地点、时间、参与人数限制、组织者、状态

6. **ActivityRegistration（活动报名）**
   - 报名信息：活动、成员、报名时间、状态、备注

7. **MyAdmin（管理员）**
   - 管理员信息：账号、姓名、密码

8. **Recruitment（招新批次）**
   - 招新信息：所属社团、批次名称、开始/结束日期、状态

9. **RecruitmentApplication（招新报名）**
   - 报名信息：招新批次、学号、姓名、性别、年级、专业、联系方式、申请部门、状态、申请时间

## 功能使用说明

### 1. 社团管理
- 访问 `/club/list` 查看所有社团
- 可以添加、编辑、删除社团
- 支持按社团名称搜索

### 2. 部门管理
- 访问 `/department/list` 查看所有部门
- 可以添加、编辑、删除部门
- 支持按社团筛选部门

### 3. 角色管理
- 访问 `/role/list` 查看所有角色
- 系统仅保留两种角色：**社长**、**普通成员**（可添加/编辑/删除，建议保持至少各一个供使用）

### 4. 成员管理
- 访问 `/member/list` 查看所有成员
- 可以添加、编辑、删除成员
- 支持按姓名搜索和按社团筛选

### 5. 活动管理
- 访问 `/activity/list` 查看所有活动
- 可以添加、编辑、删除活动
- 点击"详情"查看活动详情和报名列表
- 支持按活动名称搜索和按社团筛选

### 6. 活动报名管理
- 访问 `/registration/list` 查看所有报名记录
- 可以添加、编辑、删除报名记录
- 支持按活动和成员筛选
- 在活动详情页可以直接添加报名
- 支持导出 Excel

### 7. 招新管理
- 访问 `/recruitment/list` 管理招新批次（新建、编辑、删除）
- 访问 `/recruitment/applications/` 管理招新报名（添加、编辑、删除）
- 对「待审核」报名点击「通过」可将其转为正式成员（自动加入社团与部门）
- 支持按批次、状态筛选，支持导出 Excel

### 8. 导出
- 各列表页提供「导出 Excel」按钮，导出当前筛选结果为 .xlsx 文件

## 注意事项

1. **数据库配置**：请确保 MySQL 服务已启动，并已创建相应的数据库
2. **管理员账户**：首次使用需要创建管理员账户（见安装步骤）
3. **数据关联**：删除社团时会级联删除其下的部门和活动
4. **重复报名**：系统会自动防止同一成员重复报名同一活动
5. **参与人数**：活动的当前参与人数会根据报名状态自动更新
